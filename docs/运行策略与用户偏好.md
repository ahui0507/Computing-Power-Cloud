# 用户确认的运行策略

记录日期：2026-10-18。后续平台维护、巡检及建议应遵循以下明确选择；用户的新指示优先。

- 不做异机备份与恢复演练，后续无需提醒，不将此项作为待办或重复建议。
- 服务器没有发信权限，不发送故障邮件、不配置 SMTP。采用双节点独立故障记录及管理员端弹窗。
- 管理员故障弹窗保持到手动关闭。故障恢复、页面刷新不清除未读提醒；同一次故障已阅后不重复弹出，复发或升级重新提醒。
- 新实例临时磁盘按每张 GPU 40 GiB 分配。超限由 Kubernetes 周期检测并终止实例；需要保留的文件写入 `/data`。
- 临时磁盘按 kubelet 实际计量展示，80%/90% 分级站内提醒。手动释放前列出平台任务、实例进程、Notebook 内核及默认 tmux 会话；未完成检查明确提示未知，用户显式确认后才释放，新增任务或检查过期需要重新核对。定时释放和欠费回收继续原规则。
- 申请 GPU 算力自动附带账号共享的个人持久存储，默认 300 GiB；同一账号多卡、多实例不叠加，释放实例不删除 `/data`。当前池约 3,151 GiB，8 个默认账号共承诺 2,400 GiB；新增账号仍校验全体持久配额，不把 8 张 GPU 视为历史账号总数上限。管理员自定义额度保留。
- 已验收的 GPU 专用 identity 域、启动保护、原生多卡通信和租户隔离继续保持。其他 PCI 设备的 DMA 域不纳入 GPU 改动。

本轮上线与验证见 [临时磁盘限额与独立告警验收](临时磁盘限额与独立告警验收-20261018.md)。
