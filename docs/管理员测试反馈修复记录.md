## 使用 SSH

1. 在“我的实例 → SSH”下载 `platform-ssh.py`。本机需 Python 3.10 或更新版本。
2. Windows 在下载目录执行 `py platform-ssh.py`；Linux/macOS 执行 `python3 platform-ssh.py`。
3. 输入自己的平台邮箱和平台登录密码，保持工具窗口运行。
4. 在另一个终端执行工具显示的 `ssh -p 本地端口 root@127.0.0.1`，输入网页 SSH 对话框中的实例密码。

SFTP 和 VS Code Remote SSH 使用相同的本地主机和端口。工具支持并行连接；工具停止或重新启动后，以新显示的端口为准。工具不保存密码或访问令牌，下载文件不含凭据。原 `10.72.63.42:31256` 未建立网关映射，不作为本站对外连接入口。
