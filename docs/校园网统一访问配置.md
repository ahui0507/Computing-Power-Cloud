# 校园网统一访问配置

正式网址：**http://10.72.63.42:64022/**。

允许用户网段为 **10.240.0.0/16**：当前电脑通过 WLAN 访问节点，地址 10.240.52.192，实际前缀 /16、掩码 255.255.0.0。没有采用未承载本次连接的 192.168.1.3/24 网卡，也没有将允许范围猜成 /24。

用户已确认在控制节点复用原 SSH TCP 入口。HAProxy 将 HTTP 送到 Nginx，将 SSH 送到内部 sshd，因此无需修改网关、无需每个用户建立隧道。现有 SSH 64022/63022 的地址、账号、密码及主机密钥保持。具体结构、配置与回退见 [统一入口实施记录](复用SSH入口发布网站方案.md)。

HAProxy 和专用 Nginx 双重校验原始客户端来源；非允许来源的 HTTP 被拒绝，伪造 X-Forwarded-For 不能绕过。可信 PROXY 元数据内部端口仅监听回环地址。节点自身健康检查和已认证管理员的本机运维入口保留，不是其他网段用户的公开入口。

已从当前电脑实测正式网址、管理员和普通用户登录，并从计算节点 192.168.24.63 实测拒绝规则。所有允许网段内的用户使用相同网址和各自的平台邮箱账号，账号由管理员在「用户管理」中开通；不使用节点 SSH 账号登录网站。

曾准备的“网关增加 Web 端口映射”方案没有执行，当前发布不依赖它。未来若需要独立标准 HTTP/HTTPS 端口或域名，可以另行安排网络入口；这不是当前登录网站的前置条件。
