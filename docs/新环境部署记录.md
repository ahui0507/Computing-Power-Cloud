## GPU 诊断与未验证事项

8 张 A100 实际位于计算节点。当前加载模块及当前 7.0.0-30 磁盘模块是 595.84，NVML 595.99.02 来自 Ubuntu libnvidia-compute-595。APT 历史显示驱动用户态升级，7.0.0-38 新内核已有匹配 595.99.02 模块和 initrd，有 reboot-required 标记。没有找到额外 NVML 副本、runfile 卸载器或安装日志，SSH 检查进程没有 LD_LIBRARY_PATH/LD_PRELOAD；旧 550/580 包记录未擅自清理。

根因是用户态库更新后继续运行旧内核和旧模块。推荐维护窗口保存全部作业及容器配置后，重启到已经安装的新内核；无需先卸载或重装驱动。该方案会中断现有容器/桌面/内存作业，尚未获维护窗口和 GPU 移交授权，因此未执行。

尚未验证：修复后的 nvidia-smi、真实 GPU 容器、平台 GPU 申请/实际 CUDA 运算、实例 SSH/Jupyter、多卡训练、个人镜像保存恢复，以及 GPU 实例重建后的 /data 持久化。单元测试或控制面 Ready 不等于这些功能已正常。

公共工作镜像尚未构建/导入，新库中的测试镜像登记不代表计算节点有可运行镜像。源 6.65 GB 归档按用户决定留源。旧定时快照工具依赖 LVM，本次普通分区不适用；旧备份 timer 未启用，新的定时异机备份和完整恢复方案需另行确定。没有进行节点重启后的整机挂载验收。
