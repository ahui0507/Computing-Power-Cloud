# Jupyter测试镜像 - 离线导入说明

## 问题

系统使用K3s内置的containerd，没有Docker，无法直接构建镜像。

## 解决方案

### 方法1: 从其他机器构建并导入（推荐）

#### 步骤1: 在有Docker的机器上构建

```bash
# 在有Docker的机器上（可以是你的开发机或其他服务器）
cd test-images/jupyter-test
docker build -t jupyter-test:latest .
docker save jupyter-test:latest -o jupyter-test.tar
```

#### 步骤2: 传输到K3s服务器

```bash
# 从构建机器传输到K3s服务器
scp jupyter-test.tar control@<k3s-server-ip>:/tmp/
```

或者使用其他方式（U盘、网络共享等）将 `jupyter-test.tar` 文件传输到K3s服务器。

#### 步骤3: 在K3s服务器上导入

```bash
# 在K3s服务器上
cd test-images/jupyter-test
chmod +x import_from_tar.sh
sudo ./import_from_tar.sh /tmp/jupyter-test.tar
```

或者手动导入：

```bash
# 查找ctr命令
CTR_PATH=$(sudo find /var/lib/rancher -name ctr 2>/dev/null | head -1)

# 导入镜像
sudo $CTR_PATH images import /tmp/jupyter-test.tar

# 标记镜像
sudo $CTR_PATH images tag docker.io/jupyter-test:latest jupyter-test:latest

# 验证
sudo $CTR_PATH images ls | grep jupyter-test
```

### 方法2: 安装nerdctl（推荐用于长期使用）

nerdctl是containerd的Docker兼容CLI，可以直接构建镜像。

#### 安装nerdctl

```bash
# 下载nerdctl
cd /tmp
wget https://github.com/containerd/nerdctl/releases/download/v1.5.0/nerdctl-1.5.0-linux-amd64.tar.gz

# 解压
tar -xzf nerdctl-1.5.0-linux-amd64.tar.gz

# 安装
sudo mv nerdctl /usr/local/bin/
sudo chmod +x /usr/local/bin/nerdctl

# 验证
nerdctl version
```

#### 使用nerdctl构建

```bash
cd test-images/jupyter-test
sudo nerdctl build -t jupyter-test:latest .
```

镜像会直接构建到containerd中，无需导入步骤。

### 方法3: 使用buildah（如果可用）

如果系统已安装buildah：

```bash
cd test-images/jupyter-test
buildah bud -t jupyter-test:latest .

# 导出为tar
buildah push jupyter-test:latest docker-archive:/tmp/jupyter-test.tar

# 然后使用import_from_tar.sh导入
```

## 验证镜像

```bash
# 查找ctr命令
CTR_PATH=$(sudo find /var/lib/rancher -name ctr 2>/dev/null | head -1)

# 列出镜像
sudo $CTR_PATH images ls | grep jupyter-test
```

应该能看到 `jupyter-test:latest` 镜像。

## 添加到数据库

导入镜像后，需要将其添加到数据库：

```bash
cd backend
python ../test-images/jupyter-test/add_to_database.py
```

或者手动执行SQL：

```sql
INSERT INTO images (name, tag, description, visibility, created_at)
VALUES ('jupyter-test', 'latest', 'Jupyter测试镜像', 'public', NOW());
```

## 测试

1. 在网页中申请资源
2. 选择镜像: `jupyter-test:latest`
3. 等待Pod创建完成
4. 访问Jupyter: `http://<节点IP>:<jupyter_port>`

## 常见问题

**Q: 找不到ctr命令？**
```bash
# 查找ctr命令
sudo find /var/lib/rancher -name ctr

# 通常路径是：
# /var/lib/rancher/k3s/data/current/bin/ctr
```

**Q: 导入失败？**
- 确保使用sudo权限
- 检查tar文件是否完整
- 检查containerd是否运行: `sudo systemctl status containerd` 或 `sudo systemctl status k3s`

**Q: 镜像导入后看不到？**
```bash
# 使用完整路径查看
CTR_PATH=$(sudo find /var/lib/rancher -name ctr 2>/dev/null | head -1)
sudo $CTR_PATH images ls

# 或者使用nerdctl（如果已安装）
sudo nerdctl images
```

## 多节点集群

如果K3s是多节点集群，需要在**每个worker节点**上都导入镜像，或者：

1. 配置K3s使用私有镜像仓库
2. 在控制节点导入后，配置镜像同步
3. 或者使用DaemonSet自动同步镜像
