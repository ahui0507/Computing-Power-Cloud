# 快速导入已构建的Docker镜像

如果你已经用Docker构建好了 `jupyter-test:latest` 镜像，可以使用以下方法快速导入到K3s。

## 方法1: 使用专用脚本（最简单）

```bash
cd test-images/jupyter-test
chmod +x import_existing_docker_image.sh
sudo ./import_existing_docker_image.sh jupyter-test latest
```

这个脚本会：
1. 检查Docker中是否存在镜像
2. 导出镜像为tar文件
3. 导入到K3s containerd
4. 标记镜像
5. 验证导入结果

## 方法2: 使用更新后的build_and_import.sh

```bash
cd test-images/jupyter-test
chmod +x build_and_import.sh
sudo ./build_and_import.sh
```

脚本会自动检测Docker中是否已有 `jupyter-test:latest` 镜像，如果有会询问：
```
发现Docker中已存在的镜像: jupyter-test:latest
是否直接导入到K3s？(y/n)
```

输入 `y` 即可直接导入，无需重新构建。

## 方法3: 手动导入

如果脚本不可用，可以手动执行：

```bash
# 1. 导出镜像
docker save jupyter-test:latest -o /tmp/jupyter-test.tar

# 2. 查找ctr命令
CTR_PATH=$(sudo find /var/lib/rancher -name ctr 2>/dev/null | head -1)

# 3. 导入镜像
sudo $CTR_PATH images import /tmp/jupyter-test.tar

# 4. 标记镜像
sudo $CTR_PATH images tag docker.io/jupyter-test:latest jupyter-test:latest

# 5. 验证
sudo $CTR_PATH images ls | grep jupyter-test
```

## 验证镜像

```bash
# 查找ctr命令
CTR_PATH=$(sudo find /var/lib/rancher -name ctr 2>/dev/null | head -1)

# 列出镜像
sudo $CTR_PATH images ls | grep jupyter-test
```

应该能看到 `jupyter-test:latest` 镜像。

## 下一步

导入镜像后，需要将其添加到数据库：

```bash
cd backend
python ../test-images/jupyter-test/add_to_database.py
```

然后就可以在网页中申请资源，选择 `jupyter-test:latest` 镜像进行测试了。
