# A100 PyTorch 实际训练验证

`train.py` 使用三层卷积分类模型（356,234 个参数），对带噪声的合成图像做十分类。训练集 8,192 张、独立验证集 2,048 张，无需下载数据或安装 torchvision。必须有 A100 和 CUDA，不提供 CPU 回退。

在已分配的 A100 实例内运行：

```bash
python -u train.py --epochs 10 --batch-size 256 --output-dir results
```

每次使用一个新的输出目录。脚本运行前检查实例可见 GPU 是否已有计算进程，避免与已有训练争用。仅使用 `cuda:0` 单卡；实例分配两张卡不代表本脚本会自动使用两张卡。

输出 `report.json` 和 `checkpoint.pt`。报告检查模型和数据设备、损失下降、梯度有限、权重更新、CUDA 性能分析事件以及保存/加载后的预测一致性，并采样 `nvidia-smi` 利用率和显存。
